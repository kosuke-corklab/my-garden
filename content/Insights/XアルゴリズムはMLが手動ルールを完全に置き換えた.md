# XアルゴリズムはMLが手動ルールを完全に置き換えた

Xの「For You」アルゴリズムは、手動フィーチャエンジニアリングを完全廃止し、Grokベースのトランスフォーマーモデルにすべての判断を委ねている。

「何が関連するか」を人間が設計するのではなく、ユーザーのエンゲージメント履歴（何をlikeし・replyし・repostしたか）をそのままモデルが学習することで、コンテンツの関連性を判断する。

## なぜ重要か

これはAI時代の「設計哲学の転換」を象徴する。
従来のシステムは「人間が考えたルール → コード化」だった。
現代のシステムは「データからパターンを学ぶ → ルールは自然に出現する」になった。

ルールが不要になったのではなく、ルールがモデルの重みの中に「溶けた」。
