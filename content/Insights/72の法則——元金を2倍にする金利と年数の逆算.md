# 72の法則——元金を2倍にする金利と年数の逆算

```
72 ÷ 年数 = 必要な金利（%）
72 ÷ 金利（%） = 2倍になるまでの年数
```

「何年で2倍にしたいか」から逆算して必要な金利がわかる。あるいは「この金利なら何年で2倍になるか」を瞬時に計算できる。

## 具体的な数値

| 年数で2倍 | 必要な金利 |
|----------|-----------|
| 10年 | 7.2% |
| 12年 | 6.0% |
| 18年 | 4.0% |
| 24年 | 3.0% |
| 36年 | 2.0% |

→ 全世界株式インデックスの長期平均リターン（年利5〜7%）なら、**10〜14年で元本が2倍**になる計算。

## なぜ重要か

「投資はよくわからない」という感覚の正体は、遠い未来がイメージできないことにある。72の法則はその霧を晴らす道具。

目標（例：20年後に資産を2倍にしたい）から必要な金利（3.6%）を逆算し、現実的な手段（低コストインデックスファンド）と照合できる。
