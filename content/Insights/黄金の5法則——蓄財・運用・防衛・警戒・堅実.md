# 黄金の5法則——蓄財・運用・防衛・警戒・堅実

バビロンに伝わる、お金が「引き寄せられ、離れない」ための普遍的な5法則。

| 法則 | 要約 |
|------|------|
| **蓄財** | 収入の1/10以上を貯める者に黄金は集まる |
| **運用** | 働く場所を与えてやれば黄金は増える |
| **防衛** | 専門家の助言を聞く者から黄金は離れない |
| **警戒** | 理解できない・専門家が否定する商いに手を出すと黄金は逃げる |
| **堅実** | 非現実的な利益・甘い誘惑への盲信は黄金を失う原因になる |

## 現代への翻訳

- 蓄財 → 給与天引きの積立（先取り貯蓄）
- 運用 → インデックスファンドの長期積立
- 防衛 → 手数料の低いパッシブ運用、分散投資
- 警戒 → 自分が仕組みを説明できない金融商品には投資しない
- 堅実 → 「必ず儲かる」という話には乗らない

## 大前提

> 現代においてリスクなしにお金を増やす方法はない。

リスクを取らないこと自体が、インフレによる実質的な資産目減りというリスクを取ることと同義。
