# バビロン大富豪の教え

**著者:** ジョージ・S・クレイソン
**舞台:** 紀元前18〜4世紀のバビロニア（現イラク）

## 一言で言うと

「お金持ちとはお金をたくさん持っている人ではなく、お金の増やし方を知っている者」——その知恵を物語形式で体系化した古典。

## 背景

- バビロニアは資源が乏しく交易が盛んだったため数学・金融が発達
- 神殿での貸し付けが銀行の起源とされる
- 普遍的な教えが紀元前から現代に通じる理由はここにある

## 黄金を増やす「7つの道具」

| # | 道具 | 内容 |
|---|------|------|
| 1 | 貯金 | 収入の1/10を貯金せよ（1〜2割、3%程度で運用） |
| 2 | 欲望の優先順位 | 優先度の低い欲望を切り捨てても生活水準は変わらない |
| 3 | お金を働かせよ | 蓄えたお金自身に稼がせる |
| 4 | リスク回避 | 危険や天敵からお金を堅守する |
| 5 | 住居への投資 | より良きところに住め——心の豊かさと貯金モチベーションを生む |
| 6 | 未来への備え | 今日から将来の生活に備えよ |
| 7 | 自己投資 | 自分こそを最大の資本にせよ——成長を止めない |

## 黄金に愛される「5つの法則」

| 法則 | 内容 |
|------|------|
| 蓄財 | 収入の1/10以上を蓄える者のもとへ黄金は喜んでやってくる |
| 運用 | 懸命に働く場所（投資先）を見つけてやれば黄金は懸命に増える |
| 防衛 | お金の扱いに長けた者の助言を素直に聞く者から黄金は離れない |
| 警戒 | 自分が理解していない商いや専門家が否定する商いに手を出すと黄金は逃げる |
| 堅実 | 非現実的な利益・甘い誘惑・未熟な経験の盲信は黄金を失う原因になる |

## 現代への応用

- 現代の最適解：**外国株式のインデックスファンドの長期運用**
- 個人で情報を収集する必要がなく、原則に沿った投資手法
- 大前提：**現代においてリスクなしにお金を増やす方法はない**

## Key Claims

1. お金持ちとは「お金の増やし方を知っている者」——資産額ではなく知恵の問題
2. 収入の1/10を必ず貯蓄し、そのお金を働かせることが蓄財の基本
3. 自分が理解していない投資には手を出さない（警戒の法則）
4. 仕事はお金を稼ぐ手段ではなく「営み」を築くもの——お金は結果にすぎない
5. お金があるだけでは幸せになれない——感謝される仕事と人との繋がりが幸せの条件

## 感想・接続

最も学びになったのは「幸せの条件」。
お金は必要条件だが十分条件ではない。
情報商材を売ってお金を手にしても、他者との繋がりは生まれない。
**論語と算盤**がこの本質を捉えた作品だと感じた——道徳と経済は対立しない。
