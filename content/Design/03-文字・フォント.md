# 文字・フォント

## フォント階層とジャンプ率

![フォント階層とジャンプ率](assets/design/font-hierarchy.svg)

## フォントの使い分け

| 用途 | 推奨フォント | 理由 |
|------|------------|------|
| 長文・本文 | 明朝体 | 小さな文字でも読みやすい、フォーマルな印象 |
| タイトル・見出し | 太いゴシック体 | 目立つ、主張が強い、活発なイメージ |
| 話し言葉・吹き出し | 手書き書体 | 親しみやすさ、温かみ、アクセントとして |

- 1デザイン内で使うフォントは**最大3種類**（見出し・本文・アクセント）
- フォントだけでなく**サイズ・行間・文字間の設定も統一**する

## 見出しのジャンプ率

- 見出しは本文の**2〜8倍**のサイズが目安
- ジャンプ率が高いほどメリハリが出る
- 最低でも本文の2倍（例：本文9pt → 見出し18pt）

## 行間・文字間

- **行間**：文字の高さ × 0.7〜1.0 が読みやすい目安（7〜10pt相当）
- 広げすぎるとスカスカな印象になる
- **文字間**：文字の幅 × 0.2くらい広げると読みやすくなる
- デフォルト「0」のままで打ち込まれることが多いので意識的に調整する

## タイトルを目立たせるテクニック

| テクニック | 説明 |
|-----------|------|
| フチドリを入れる | 文字の**外側**にアウトラインをつける（内側はNG：文字がつぶれる） |
| 背景に帯を敷く | タイトルエリアの境界線がハッキリし、存在感が増す |
| 1文字ずつバラす | 文字を少しずつずらして配置、動きとボリュームが出る |
| キーワードを大きくする | 1語だけ大きくする（手書きPOPの定番）、全部読まなくても内容がわかる |
| 少しだけ傾ける | 整列グリッドに対して数度傾けるだけで目が行く |
| 言葉の一部を枠外に出す | 吹き出しなどで囲んだ文字の一部を外にはみ出させるとボリューム感 |

## 本文を読みやすくするテクニック

| テクニック | 説明 |
|-----------|------|
| 周りに余白を取る | 本文近くに別の要素があると読みにくい、クッションの余白を作る |
| 2列に分ける | A4横方向いっぱいに文字を詰めない、2列にすると視線の移動が減る |
| 段落ごとに区切る | 1段落は3〜5行が目安。段落間は十分な余白 |
| 1文字目を大きくする | 「ドロップキャップ」効果でアイキャッチになる |

## 数字のデザイン

- 数字には**単位を小さく**するとインパクトが出る（「100 万人」のように）
- グラフのラベルは**全部同じサイズにしない**、強調したいデータを大きく

## やってはいけない文字NG

| NG | 代替 |
|----|------|
| 文字をぐにゃぐにゃに変形させる | 周囲の装飾でにぎやかにする |
| 装飾しすぎる（グラデーション・影・多色） | シンプルなデザインで読みやすさ優先 |
| やたらとポップ書体を使う | アクセントとして最小限に使う |
| 太いゴシックを本文に使う | 本文は明朝体か細めのゴシック体 |
| 手書き書体を長文に使う | 吹き出しや見出しのアクセントのみ |
